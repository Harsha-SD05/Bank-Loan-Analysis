# 🏦 Bank Loan Analysis | PostgreSQL & Power BI

## 📌 Project Overview

This project focuses on analyzing bank loan data using PostgreSQL and Power BI to understand loan applications, funded amounts, received payments, interest rates, and borrower behavior.

An interactive Power BI dashboard was developed to monitor loan performance, identify trends, and generate meaningful business insights.

## 🎯 Project Objectives

- Analyze total loan applications and funded amounts.
- Track total amount received from borrowers.
- Compare Month-to-Date (MTD) and Month-over-Month (MOM) performance.
- Identify good loans and bad loans.
- Analyze loan performance by state, purpose, term, and employment length.
- Understand loan status and borrower characteristics.

## 🛠️ Tools & Technologies

- **PostgreSQL:** Data analysis and SQL queries.
- **Power BI:** Interactive dashboard development.
- **DAX:** KPI calculations and performance metrics.
- **Power Query:** Data transformation.
- **Microsoft Excel / CSV:** Dataset handling.

## 📂 Dataset

The project uses a financial loan dataset containing information about:

- Loan ID and Member ID
- Loan Amount
- Total Payment
- Interest Rate
- Debt-to-Income (DTI) Ratio
- Loan Status
- Loan Purpose
- Employment Length
- Home Ownership
- Address State
- Issue Date
